# Nova York — Narrativa Cinematográfica

Uma jornada visual imersiva e guiada por scroll pela cidade de Nova York. Oito atos cinematográficos combinando parallax, tipografia e design de movimento.

## Executar Localmente

**Pré-requisitos:** Node.js

1. Instalar dependências:
   `npm install`
2. Executar o app:
   `npm run dev`
3. Abrir [http://localhost:3000](http://localhost:3000)

## Build

`npm run build` — gera na pasta `dist/`
